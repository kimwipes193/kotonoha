# ことのは — 交換日記

匿名の誰かと、1日1回だけ心を交換する日記アプリ。黄色・空色・ピンクを使った、スマートフォン対応のWebアプリです。

## 機能

- Googleアカウントでログイン／ログアウト。ChatGPTアカウントは不要
- 日記・気分・国や地域・便箋・ステッカー
- 日本時間0時を基準に1日1通。送信後30秒以上待って、相手の投稿を1件ずつ割り当て
- 送受信した日記帳、絵文字リアクション、通報、ブロック
- ルールベースの個人情報・攻撃的表現チェック
- 1日1回の無料ガチャ（全24種類、各約4.17%、重複あり）
- D1による永続保存。ブラウザ保存は下書きだけ

## 公開

**[GitHub＋Cloudflareの設定手順](docs/GITHUB-CLOUDFLARE.md)**

ソースと公開ワークフローは準備済みです。実際にGoogleログインを利用するには、公開先のCloudflare設定とGoogle OAuthクライアントの登録が必要です。未設定の状態をログイン成功として扱いません。

旧Sites公開版は別環境です。ここでのコード変更だけでは公開版や既存データは変更されません。Googleログインへの既存データの引き継ぎは別途必要です。

## 開発と検証

Node.js 22.13以上。

```
npm ci
npm test
npm run typecheck
npm run build
npm run dev
```

DB変更後は`npm run db:generate`。適用済みのSQLは変更せず、マイグレーションを追加してください。

認証テストは隔離したSQLiteと署名付きテストJWTを使い、期限・発行者・宛先・nonce・state・セッション失効・他人の日記へのアクセス拒否を検証します。実際のGoogleアカウントによる本番ログインは、OAuth設定後に確認が必要です。

## 認証とデータ

Googleから要求するのは`openid email`だけで、メール本文への権限はありません。署名・宛先・発行者・期限・nonceを検証し、サーバーにはGoogleの固定IDとハッシュ化したセッショントークンを保存します。日記交換相手に名前、メールアドレス、固定IDは返しません。

セッションは30日、ログイン途中のstateは10分で失効します。ログアウト時にサーバーのセッションも失効します。認証ヘッダーの自己申告によるログインは許可しません。

広告配信と自由文の自動翻訳は準備中です。見本の日記は架空で、対訳を同梱しています。自動チェックは網羅的ではなく、通報への対応体制は別途必要です。国・地域は自己申告、日記帳の表示は直近100件です。

WebMCPの`stage_diary`は下書きの設定のみを行い、日記を送信しません。対応ブラウザでの呼び出し検証は未実施です。

## ぽすとのごほうび

ステッカー26種類＋便箋2種類（うち行動特典4種類）。称号13種類はアカウントに保存されます。日本時間の月曜0時から日曜までの100なでで肉球印を週1枚獲得。累計回数と称号はリセットせず、ステッカーは消費されません。交換回数は受信済みの日記の生涯件数で、画面の100件上限に影響されません。書体はゴシック・明朝・等幅の3種類で投稿と一緒に保存されます。実際のフォントは端末の搭載書体によります。
