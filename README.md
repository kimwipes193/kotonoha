# ことのは — 交換日記

匿名の相手に、1日1通だけ今日の気持ちを届けるWebアプリ。ポップな黄色・空色・ピンクのUIで、スマートフォンにも対応しています。

## 実装済み

- 10〜1,000文字の日記、気分、国・地域、便箋・ステッカーの選択
- サーバー保存、日本時間0時を基準にした1日1通の制限、重複送信防止
- 自分以外の日記を1投稿につき1件だけ割り当て。投稿から最低30秒の待ち時間。候補がなければ待機
- 送信済み／受信した日記帳、絵文字リアクション、通報、双方のブロック関係を考慮した振り分け
- 個人情報・攻撃的な表現のルールベースチェック（網羅的なモデレーションではありません）
- 無料の1日1回ガチャ（8種類、各12.5%、重複あり）、獲得アイテムの永続保存
- 認証ユーザーのIDによる所有権チェック。相手にID、名前、メールは返さない
- 下書きだけ端末内に保存。投稿・履歴・アイテムはD1に保存

## 試用版の範囲

初回は本人限定の非公開サイトです。他の参加者がいなければ実際の交換は待機します。「見本」は架空のフランス語日記で、対訳とリアクションを試せます。

広告配信・視聴完了検証と自由文の自動翻訳は未接続です。画面に「準備中」と明示し、広告未視聴で追加投稿を許可しません。実用公開には広告プロバイダーとの連携、翻訳サービス、通報の運用体制、多言語でのモデレーション強化が残っています。通報は保存され、対象を即時非表示にしますが、運営への外部通知は行いません。

日記帳は直近100件を表示します。それ以前の記録もデータベースに保存されます。現在の国・地域は自己申告です。ログイン基盤はSites提供のものを使っています。

## 開発

Node.js 22.13以上。`npm run install:ci`、`npm run dev`。`npm run build`でWorkerを生成します。DB変更時は`npm run db:generate`で追加マイグレーションを作成してください。

ローカルDBの初回セットアップ（ビルド後）：

```
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_sturdy_nico_minoru.sql
```

検証：`node tests/rules.mjs`、`python tests/database.py`、`npx tsc --noEmit`。

WebMCPの`stage_diary`は下書きを編集するだけで送信しません。対応ブラウザでの登録・呼出検証は未実施です。
