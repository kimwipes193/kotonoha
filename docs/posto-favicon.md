# Posto favicon

Generated with the built-in image_gen tool using `public/mascot.png` as the character reference.

Source: `public/posto-face.png`
Browser icon: `public/posto-favicon.png` (64 × 64)
Apple icon: `public/posto-apple-icon.png` (180 × 180)

## Final generation prompt

Use case: logo-brand. Create a square favicon for Kotonoha from the reference mascot Posto. Only the cat HEAD, no body, paws, tail, envelope or text. Preserve the distinctive single folded right ear (viewer right), asymmetric huge ivory eyes with small dark pupils, tiny peach nose and funny slightly puzzled expression. Flat clean illustration, navy #211f30 head, ivory #faf9f5 eyes, pale peach #ffcdba inner ears and nose. Solid pastel butter yellow #ffe29a square background. Head fills 85% of image with safe margin and strong recognizable silhouette at 32 pixels. Minimal chunky shapes, no thin whiskers, no texture, no gradients, no shadow. One centered face icon, not a mockup or icon sheet.

The generated source has transparency. Browser PNG preserves alpha; Apple PNG uses the menu yellow background. Icons are resized exports of the generated image.

## Page titles

Japanese primary page headings use outlines from the installed chika-Regular.ttf for hiragana and umeboshi_natural.ttf for kanji and katakana. No font binary is distributed. Other UI languages keep live text and existing fonts. Menu labels are unchanged.
